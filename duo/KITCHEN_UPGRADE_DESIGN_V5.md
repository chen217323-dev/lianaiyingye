# 《恋爱营业中》V5·厨房经营升级详细设计（方案，尚未开发）

状态：**设计已由用户确认，留待下次升级开发**。当前不要修改现有线上代码、数据库和积分钱包。
当前基础：两个云端账号（内部role=owner/customer，UI显示老公/老婆）；菜单22道；老婆下单先扣积分；老公把订单标为completed/送达后获得菜品全额积分；双方各自独立积分；商城10项；愿望完成双方各+30。

## 核心定位
「老公掌勺、老婆能点菜也能出菜单的两人私人餐厅」。强调生活中能真实用、订单进度清楚。菜品消费积分从老婆转给老公；按10分制评价产生有限的额外奖励积分（待用户确认归属），厨师经验XP则独立于可消费宠爱币。

## 首页与导航
沿用现有首页、底部导航和情侣合照，不加太多底栏图标。老婆首页增加「🍳 今晚吃什么」「🥬 老婆自创菜」「📅 预约点餐」「❤️ 我的美食评价」；老公首页增加「👨‍🍳 我的厨房」「📋 待制作」「🥬 自创菜审核」「🏆 厨师成长」。访问时以当前登录角色显示入口；原点菜、任务、商城、愿望树、悄悄话照旧。

## 老婆端：厨房点菜屏
- 顶部：当前积分、厨房状态（营业中/暂时休息）、今日推荐菜。
- 分类菜谱继续使用现有22道菜；新增加「今日推荐」「暂时售罄」，图标、菜名、积分价格、描述。可选菜图（初版可先使用emoji，不要求照片）。
- 点击一道菜进入「点菜详情」：口味偏好（微辣/中辣/特辣/不辣，默认正常）、可勾选少盐/少油/不放香菜等备注、其他忌口文本（自述非专业食物过敏审核）；期待时间（尽快 / 自选韩国时间预约）、给老公一句话，提交前显示确认。
- 预约规则：预约时间只表示希望用餐时间；老公可接受或提出调整，老婆确认改时；首版不做无人值守自动做饭。
- 默认一家小店一单一道菜（不改变现有订单模型），「多菜购物车」「加料收费」「套餐组合」可留下一阶段。

## 老婆端：自定义菜单（新增需求）
- **不再只有老公能加菜**。老婆点击「🥬 老婆自创菜」→「+ 想吃一道新菜」，自己填写菜名、分类、emoji、菜品介绍、口味偏好和一句「为什么想吃」。可以从当前已有分类选择，也可以自拟新分类。
- 老婆创建后立即出现于双方可见的「老婆点名菜」列表，初始状态「等老公确认能不能做」；可以自由编辑/撤回**自己提交、尚未确认**的菜。不能修改或删除老公原来管理的22道菜，避免意外覆盖。
- 老公收到新菜通知后，可以选择「我会做」并确定积分价格、预计可供时间；或「暂时做不了」并留下备注。确认后才开放下单，避免尚未确认的菜被下单、出现无法做饭的情况。
- 老公仍负责菜品是否供应、暂停售罄、积分价格与厨房库存；老婆修改已通过审核的菜名/配方时，重新进入「待确认」，原菜品价格及已有订单价格快照不变。
- 老婆自创菜确认上架以后，使用与原菜单完全相同的点菜流程：扣老婆的积分→老公制作→送达后老公赚菜价积分→老婆评价。无单独第二套账本。
- 双方都能查看菜品是谁创造的。卡片角标可显示「👑 老婆点名」「👨‍🍳 老公原创」。
- 本次先支持文字＋emoji，无需额外上传菜图；需要的话后续再和愿望树类似增加单张菜品照片（需要私密云端存储权限）。

## 老公端：厨房工作台
- 顶部：老公自己的积分、今天收到的订单数、待制作、累计已送达订单和厨师经验等级。
- 今日营业：可切换营业/暂时休息；老公自行设置今日推荐；菜单临时售罄/上架；这两项不删除菜品。
- 新订单卡：菜名/价格/口味和忌口备注/希望吃饭时间/下单时间。
- 状态流转：待接单 → 制作中 → 已做好待取 → 已送达；也可取消订单并退款。兼容旧订单的pending、preparing、completed、cancelled（迁移时保留旧记录与收入语义）。
- 「已送达」只能由老公点击，成功那一刻到账菜品积分；点两次不能重复到账。
- 老婆能看到进度；站内提示和轮询/实时刷新同步。暂不承诺系统推送。

## 双方：10分制美食评价与厨师成长
- **评分改为满分10分**，只有老婆在订单被老公标为「已送达」后才能提交；每笔真实送达订单最多评价一次，评价是针对**这次用餐订单**而非永久改写整道菜的分数。
- 老婆可以选择1—10分、写一句评价（可不写）。菜品页面累计展示该菜的历史平均分、评价数量和评价摘要；新菜没有评价显示「等待老婆的第一次点评」。
- 同一订单只能获得一次评分奖励。默认提交分数后锁定奖励：允许修改评价文字，不允许通过来回改分追加积分。
- **已确认的额外评分奖励规则：由老公获得。** 即原来的做饭收入不变，老婆评分后按照分数给老公发额外奖励；这笔奖励由系统生成，不再从老婆钱包扣一次钱。不给差评设扣分或惩罚。
- 评分转换为可消费宠爱币的建议表：

| 老婆的菜品评分 | 老公额外获得 |
|---|---:|
| 1—3分 | 0 ◎ |
| 4—5分 | +5 ◎ |
| 6—7分 | +10 ◎ |
| 8—9分 | +15 ◎ |
| 10分 | +20 ◎ |

- 推荐每日最多有3笔订单的评分获得奖励，最高+60◎/天；超额仍能评价但不再发当日额外积分，以免评价奖励无限刷分。既往历史订单不自动补发评分奖励。
- 老公在「主厨荣誉墙」看已送达菜品数、平均美食分、累计做饭收入、评分额外奖励、厨师等级、老婆的评价、最受欢迎的菜。

- 老公在「主厨荣誉墙」看已送达菜品数、累计做饭收入、厨师等级、老婆的好评、自己做过最多次的菜；可解锁「第一次开火」「连续做10顿饭」「米线专家」等称号。
- 厨师XP从可消费积分独立；每个有效送达订单 +10XP，每日最多前三单计XP（最多30XP/天），取消/退款不发XP。
- 初始经验等级建议：L1 新晋主厨（0XP）、L2 暖心主厨（50XP）、L3 爱心大厨（150XP）、L4 金牌主厨（300XP）、L5 私房料理大师（600XP）。阈值可在后续自定义。
- XP解锁装饰/称号，不产生免费宠爱币，不随评分高低改变，防止出现「评价差就扣分」的关系压力。

## 积分规则（沿用并强化）
假设老婆余额300◎，老公余额120◎；一道菜80◎：
1. 老婆确认下单：老婆300→220；老公仍120（未做饭前不发放积分）。
2. 老公点击「已送达」：老公120→200，老婆仍220；老公同时获得10XP（受每日上限约束）。
3. 送达前合规取消：老婆220→300，老公仍120，XP不增加。若已经完成，不能用普通取消接口倒扣，争议需双方另行协商。
4. 美食评价：如果老婆给本次订单10分，**推荐由系统再奖励老公+20◎**，则老公余额200→220，老婆仍220；额外奖励属于明示的系统积分发行，与老婆已经支付的80◎分开记账。低分不扣既有收入。该奖励机制**已获用户确认，待下次开发**。
5. 原来完成愿望双方各+30的奖励保持不变；商城照旧独立扣分；老公和老婆内部身份/钱包不变。
